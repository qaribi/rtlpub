# rtlpub

ابزار آفلاین و فقط‌خواندنی برای بررسی اولیهٔ محتوای فارسی و راست‌به‌چپ:
متن UTF-8، XHTML و EPUB 3 بدون رمزگذاری. گزارش، ایرادهای احتمالی Unicode،
زبان و جهت، heading/alt و پیوندهای داخلی را برای بازبینی انسانی نشان می‌دهد.
کتاب یا متن اصلی را تغییر نمی‌دهد؛ وابستگی اجرایی خارج از Python ندارد.

Python 3.12 یا جدیدتر لازم است. پس از دریافت مخزن، در محیط مجازی:

~~~sh
python -m pip install .
rtlpub check examples/persian.xhtml --format json
rtlpub check book.epub --fail-on warning
~~~

کد خروجی ۰ یعنی یافته‌ای به آستانهٔ انتخابی نرسیده، ۱ یعنی یافته به آستانه رسیده
و ۲ یعنی ورودی نامعتبر، پشتیبانی‌نشده یا بررسی ناقص است. آستانه پیش‌فرض error
است؛ هشدارها ممکن است با خروجی ۰ همراه باشند.

نیم‌فاصله، ی/ک عربی در بخش فارسی، کنترل bidi و NFC فقط هشدارند و خودکار اصلاح
نمی‌شوند. زبان و جهت از والد XHTML ارث می‌رسند؛ بخش انگلیسی LTR، نقل‌قول عربی،
dir=auto و alt خالی تزئینی مجازند. گزارش متن کتاب را نقل نمی‌کند؛ نام فایل‌ها
ممکن است خصوصی باشند، پیش از اشتراک گزارش آن‌ها را بررسی کنید.

این ابزار مکمل EPUBCheck و Ace است و گواهی کامل EPUB یا دسترس‌پذیری صادر نمی‌کند.
EPUB 2، DRM و فونت مبهم‌سازی‌شده، HTML غیرXML و ارجاع‌های CSS/SVG فعلاً پشتیبانی
نمی‌شوند. جزئیات سقف‌های امنیتی و محدودیت‌ها در README انگلیسی و SECURITY.md است.
همه نمونه‌ها مصنوعی‌اند. پروژه تازه است و سابقهٔ نگهداری و پذیرش عمومی اثبات نشده.
